# 小组长使用手册

小组长既要写自己的周报（老师身份的组长选填），又要管理本组。侧栏因此分成两组：“我的”放个人的事，“小组管理”放小组的事。自己写周报的方法见《组员使用手册》。

## 1. 侧栏怎么分

### 我的

- 我的周报：自己的本周周报、待反馈的批示、我的任务、历史周报。老师身份的组长周报选填，不计入提交率。
- 我的任务：自己的个人任务，以及别人派给你的任务。

### 小组管理

- 小组概览：登录后默认在这里。本组本周、上周的提交率和小组卡片；顶部一行提醒你自己的周报状态和待反馈的批示。
- 各小组名：直接进入你带的每个小组的小组页。
- 周报管理：按周看名单，免交、退回、导出。

## 2. 看组员的情况

1. 在侧栏“小组管理”里点小组名，进入小组页。
2. 最上面是组员列表：每个人的身份标签、课题、本周周报状态、进行中和延期的任务。
3. 点某个组员，进入成员阅览：小组、组长、当前任务、任务甘特图，下面是周报，默认显示最近一次正式提交的那一周。周报先列要点，点要点展开详细阐述，也可以点“全部展开”。
4. 用“上一周 / 下一周”切换周，用“上一位 / 下一位”在组内连续翻看。

## 3. 查看模式和编辑模式

打开页面默认是“查看模式”：只能看，不会误改。要修改时，点页面右上角“✎ 进入编辑”，页面顶部会出现一条黄色横幅；改完点横幅上的“✓ 完成编辑”回到查看模式。

派任务、改进度、设课题、退回、免交、撤回批示，以及成员、分组、系统设置里的修改，都要先进入编辑模式。写批示和导出在查看模式下就能做。

## 4. 给组员派任务

1. 小组页 → 右上角“进入编辑” → 找到“添加小组任务”。
2. 填名称、开始和结束日期，在“负责人”里勾一个或几个组员，点“添加任务”。只有一个日期的关键节点（如中期检查）用右边的“新里程碑”。
3. 负责人会在自己的首页和“我的任务”里看到，并自己更新进度。你可以在小组任务列表里修改、更新进度或删除。

## 5. 给组员设课题

1. 小组页 → 右上角“进入编辑”。
2. 组员列表里每个人下面有“课题”输入框，填好点“保存”；清空后保存就是删掉课题。

> **提示：** 可以给本组所有人设课题，包括自己。同时在两个组的人，以最后一次保存为准。年级和身份（硕士、博士、老师）由最高权限设置。

## 6. 退回周报

组员交的周报需要补充时：打开他的成员阅览页 → “进入编辑” → 周报下方“退回修改”，写清原因（必填）。组员首页会看到原因，修改后重新提交。退回期间，统计仍使用他上一次的正式版本。

## 7. 周报管理：免交和导出

- 侧栏“周报管理”默认显示本周，可以切换周、选择看哪个小组。
- 名单里每个人的状态：未提交、逾期未交、已提交、逾期已交、免交、待修改。
- 免交（编辑模式）：某人这周请假等情况，可以设为本组免交，不计入应交和提交率；可以撤销。
- 老师自愿写的周报单独列在名单下面：可以查看、退回、勾选合订，不计入应交和提交率，也不进统计 Excel。
- 导出：选好人员后可以生成合订的 Word / PDF（后台生成，完成后在导出任务里下载），或下载统计 Excel。

## 8. 这些事请找最高权限

- 加人、删人、调整分组、任免组长。
- 改年级和身份（硕士、博士、老师），重置密码。
- 全局免交（对所有小组都生效的免交）。
- 写批示：批示只有最高权限能写；组长和组员一样会收到批示并反馈。
