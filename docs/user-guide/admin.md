# 最高权限使用手册

最高权限管理整个系统：账号、分组、全部成员的周报和统计，并且可以写批示。最高权限账号只做管理，不写周报。

## 1. 侧栏

- 首页：全体本周、上周提交率，各小组卡片，批示的新反馈。
- 批示记录：写过的全部批示和每个人的反馈。
- 周报管理：按周、按范围看名单，免交、退回、导出。
- 成员管理：账号、身份、年级、课题、密码、停用，批量导入。
- 分组管理：建组、加人、任免组长。
- 系统设置：站点名、详细阐述的最少字数等。

## 2. 查看模式和编辑模式

打开页面默认是“查看模式”：只能看，不会误改。要修改时，点页面右上角“✎ 进入编辑”，页面顶部会出现一条黄色横幅；改完点横幅上的“✓ 完成编辑”回到查看模式。

派任务、改进度、设课题、退回、免交、撤回批示，以及成员、分组、系统设置里的修改，都要先进入编辑模式。写批示和导出在查看模式下就能做。

## 3. 添加成员（批量导入）

1. 成员管理 → 右上角“批量导入”。
2. 在 Excel、WPS 或在线表格里选中几行复制，粘贴到文本框。最少只要“姓名、年级、课题名称”三列；要分组就加“所在小组”“担任组长的小组”，要指定账号、密码就加“账号”“密码”。
3. “年级”写成“2026级硕士”“2021级博士”或“老师”。
4. 选好“新成员没填小组的，加入”哪个组，先点“检查”，没问题再点“导入”。
5. 没填密码的，导入完成页会显示自动生成的初始密码，只显示这一次：点“下载账号和初始密码”保存，再分别发给本人。

> **提示：** 没填账号就用姓名当账号，同名的人请另填账号（如学号）。导入是增量的：已有的人不会重复建，也不改密码、姓名和分组，只更新表里填了的年级和课题。人多时可以先点“下载成员表”，在后面加人、补信息后再导入。

## 4. 管理已有账号

成员管理 → “进入编辑”，表格里每个人：

- 身份 / 课题：选硕士、博士、老师或学生，填年级（入学年份），可以改课题，点“保存”。设为老师后周报改为选填、不计入提交率。
- 重置密码：给忘记密码的人设一个新密码，再告诉本人。
- 停用：选从下周或以后哪一周起停用（如毕业），从那周起不能登录，历史记录保留。
- 成员顺序：决定名单和合订导出里的先后。

## 5. 分组管理

- 进入编辑后可以新建小组、改名、归档。
- 把人加入小组：选成员、角色（组员或组长）和从哪天所在的周起生效；可以选过去的周补录。
- 任免组长、结束某人在组里的关系：选日期，从那一周起生效。
- 一个人可以在多个组，一个组可以有多名组长。组长只能看到和管理自己当前所带小组的人；组员的课题由组长设置。

## 6. 看周报和写批示

1. 首页点小组卡片 → 小组页 → 点组员，进入成员阅览，看任务甘特图和周报。
2. 写批示：成员阅览页周报下方“写批示”（针对这一周的周报），任务旁的“写批示”（针对任务），小组页底部“写批示”（针对全组）。在查看模式下就能写。
3. 收件人反馈后，首页“批示反馈”和侧栏“批示记录”会显示新反馈，看过点“已阅”。批示写好后不能修改，可以在编辑模式下撤回。

## 7. 周报管理

- 选择周和范围：全部人员、未分组成员或某个小组。
- 免交（编辑模式）：在“全部人员”范围里设的是全局免交，在某个小组范围里设的是该组免交。
- 退回（编辑模式）：写清原因，成员修改后重新提交。
- 老师自愿写的周报单独列在名单下面，可以查看、批示、退回、勾选合订，不计入提交率和统计 Excel。
- 导出：合订 Word / PDF、统计 Excel。

## 8. 系统设置

- 站点名称。
- 详细阐述的最少有效字符数（默认 20），改了以后只影响之后的提交。
- 运行状态。

## 9. 账号安全

- 最高权限账号的密码在左下角“修改密码”里改；忘记了需要服务器管理员在服务器上重置。
- 导入后下载的“账号和初始密码”含明文密码，发给本人后请删除。
